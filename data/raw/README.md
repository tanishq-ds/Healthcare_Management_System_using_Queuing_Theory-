# Raw Data Files

## Dataset Information

This project uses two CSV files for training ML models:

### Files Required:

1. **`patient_priority.csv`** (6,963 records)
   - Source: Combined heart disease + diabetes datasets
   - Features: 17 medical attributes + Ward Type label
   - Size: ~1.2 MB
   - **Not tracked in Git** (see `.gitignore`)

2. **`patients.csv`**
   - Source: Hospital patient demographics
   - Features: Patient ID, name, age, gender, admission date, status
   - Size: ~800 KB
   - **Not tracked in Git** (see `.gitignore`)

## How to Get the Data

### For Project Reviewers/Collaborators:

Contact the repository owner to obtain the dataset files, then place them in this directory:
```
data/raw/
├── patient_priority.csv
└── patients.csv
```

### For Development/Testing:

Generate synthetic sample data:
```python
# Run this in your notebook or terminal
python scripts/generate_sample_data.py
```

This creates sample CSV files for testing the system without real patient data.

## Data Schema

### patient_priority.csv

| Column | Type | Description |
|--------|------|-------------|
| age | int | Patient age in years |
| gender | int | 0=Female, 1=Male |
| chest pain type | int | 1-4 (type of chest pain) |
| blood pressure | float | Systolic BP (mmHg) |
| cholesterol | float | Serum cholesterol (mg/dL) |
| max heart rate | float | Maximum heart rate achieved |
| exercise angina | int | 0=No, 1=Yes |
| plasma glucose | float | Plasma glucose level (mg/dL) |
| skin_thickness | float | Skin thickness (mm) |
| insulin | float | Insulin level (μU/mL) |
| bmi | float | Body Mass Index |
| diabetes_pedigree | float | Diabetes pedigree function |
| hypertension | int | 0=No, 1=Yes |
| heart_disease | int | 0=No, 1=Yes |
| smoking_status_encoded | int | 0=Never, 1=Former, 2=Current |
| Residence_type_encoded | int | 0=Rural, 1=Urban |
| Ward Type | string | Target label (6 ward types) |

### patients.csv

| Column | Type | Description |
|--------|------|-------------|
| patient_id | string | Unique patient identifier |
| name | string | Patient full name |
| age | int | Patient age |
| gender | string | Male/Female |
| admission_date | date | Date of admission |
| status | string | Active/Discharged |

## Privacy Notice

⚠️ **No real patient data is included in this repository.**
